
# SQL Practice Repository

This repository contains SQL practice files and sample databases designed to improve SQL skills through hands-on exercises. It includes datasets, queries, and interview preparation materials covering beginner to intermediate SQL concepts. The project helps learners understand database operations such as filtering, sorting, grouping, joins, aggregate functions, subqueries, and data manipulation.

## Repository Structure

- **Interview/** – SQL interview questions and practice queries.
- **Online_Book_Store/** – Database project for an online bookstore with sample tables and queries.
- **SQL Notes/** – Notes covering important SQL concepts and syntax.
- **Joining_Data.sql** – Practice queries for INNER, LEFT, RIGHT, FULL, and SELF JOIN operations.
- **airbnb_listings.sql** – Airbnb dataset for writing analytical SQL queries.
- **cars.sql** – Sample car database used for filtering, aggregation, and reporting exercises.
- **franchises.sql** – Franchise dataset for practicing joins, grouping, and data analysis.
- **readme.md** – Repository documentation.

## Topics Covered

- SELECT Statements
- WHERE, ORDER BY, LIMIT
- GROUP BY & HAVING
- Aggregate Functions
- SQL Joins
- Subqueries
- CASE Statements
- String & Date Functions
- Views and Indexes
- Data Analysis Queries

## Purpose

This repository is intended for students, beginners, and interview candidates who want to strengthen their SQL skills through practical examples. Each SQL file contains real-world datasets and exercises that improve query writing, logical thinking, and database problem-solving abilities. Regular practice with these examples helps build confidence for technical interviews and real-world database development.
